# XML (Extensible Markup Language) Commands

Commands for working with XML files.

Click on a Command name for a detailed description.

| Command | Description |
| --- | --- |
| [XMLAdd](./XMLAdd.md) | Add a new element/text/attribute to an XML file. |
| [XMLCount](./XMLCount.md) | Count the number of times an XPath match is found in an XML file. |
| [XMLDelete](./XMLDelete.md) | Delete an XML path/value. |
| [XMLFormat](./XMLFormat.md) | Format and indent the XML file for easy human reading or compact it for smaller size. |
| [XMLQuery](./XMLQuery.md) | Read XML values and return text or xml results. |
| [XMLRead](./XMLRead.md) | Read an XML value. |
| [XMLReadList](./XMLReadList.md) | Read XML values and return them as a list. |
| [XMLRename](./XMLRename.md) | Rename a value in an XML file. |
| [XMLUpdate](./XMLUpdate.md) | Update the value of an existing Attribute/Element. |
| [XMLValidate](./XMLValidate.md) | Verify the integrity and structure of an XML file against either an XML Schema (XSD) or a Document Type Definition (DTD), or a simple structural validation check. |
